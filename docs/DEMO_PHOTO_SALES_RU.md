# Демо-работы в продаже

Семь существующих демо-работ (шесть фотографий и одно видео) получают
демонстрационные цены от 18 до 65 USD. В маркетплейсе они отмечены как демо,
а в ленте и портфолио получают такой же ценник поверх изображения. Фильтр
«В продаже», тип работы, жанр, поиск, диапазон цены, сортировка и пагинация
используют единый серверный каталог. В увеличенном просмотре покупка демо
недоступна; сервер также отклоняет её до обращения к кошелькам и заказам.

Наполнение не загружает новые изображения, не создаёт оригиналов, не меняет
профили, фотографии, голоса, отзывы или реальные продажи. Повторный запуск
сохраняет существующие демо-позиции, включая изменённую цену и статус HIDDEN.
Приватные, удалённые, отклонённые работы и отключённые владельцы не возвращаются
в выдачу. Изменение владельца, учётных данных или обнаружение чужой продажи
прерывает транзакцию. Сначала должны быть подготовлены демо-батлы и челленджи.

## Обновление сервера

PuTTY, сервер проекта:

```sh
cd /opt/gprn && git pull --ff-only && docker compose --env-file .env.production -f docker-compose.production.yml build web && docker compose --env-file .env.production -f docker-compose.production.yml up -d --no-build --no-deps --force-recreate api web worker && docker compose --env-file .env.production -f docker-compose.production.yml run --rm --no-deps seed-photo-sales
```

Последний шаг запускает одноразовый контейнер: одно ядро, 256 МБ, принудительный
лимит 60 секунд. `--rm` удаляет его после завершения. Новые миграции не нужны.
Успешный вывод содержит `Demo media listings: created 7` при первом запуске
или `preserved 7` при повторном; недоступные работы учитываются отдельно.

Повторить только наполнение после сборки нового образа:

```sh
cd /opt/gprn && docker compose --env-file .env.production -f docker-compose.production.yml run --rm --no-deps seed-photo-sales
```
