# Исправления технического SEO-аудита

Источник: «Техаудит SEO: photoapp.metarp.top», 14.10.2026. Изменения: 17.10.2026.
Ограничение владельца: сохранить внешний вид и функциональность.

## Исправлено в исходниках

- Отдельные title, description, canonical, Open Graph и Twitter metadata для разделов, публичных профилей, выбранных фотографий, публикаций, челленджей и доступных в очереди батлов.
- Hreflang связывает соответствующие страницы на всех 14 языках, включая параметры конкретного материала; x-default ведёт на английскую версию. Фильтры не создают отдельные индексируемые дубликаты.
- Публичные фотографии, портфолио, публикации, главная, эксперты и каталог продаж получают начальные данные на сервере и используют существующие компоненты. Клиентские фильтры, обновления, авторизация, формы, голосование и покупки сохранены.
- Серверные запросы ограничены 2,5 секундами, не передают cookies/Authorization и не используют персональные API. Личные сообщения, кошелёк и приватные оригиналы не сериализуются в серверный HTML.
- Публичная выдача батлов и участников челленджей дополнительно проверяет приватность, удаление, модерацию и активность владельцев. Сценарий очереди для авторизованных участников не изменён.
- Sitemap основных разделов исключает личный кабинет, администрирование, взаимодействия и предложения. Динамические sitemap материалов разделены по языкам; все перечислены в robots.txt. У статических страниц нет выдуманной даты обновления; у материалов используется дата из БД.
- Источник sitemap исключает демо-аккаунты по зарезервированным ID и именам, демо-публикации, скрытые/удалённые/непроверенные работы и служебные изображения профиля. Демо-профили и демо-материалы имеют noindex, но остаются видимыми на сайте.
- Добавлена невидимая JSON-LD разметка Organization/WebSite, BreadcrumbList, реальных публичных ProfilePage/Person и Event. Нет выдуманных оценок, отзывов, цен, посещаемости или организаторов демо-мероприятий. Пользовательский текст экранируется.
- Общая OG-картинка 1200×630, изображения конкретных материалов для ссылок и PNG Apple Touch Icon 180×180. SVG-иконка браузера сохранена.
- Четыре PNG-обложки суммарно 9 644 037 байт заменяются при отображении оптимизированными WebP суммарно 1 363 992 байта; исходники и старые URL сохранены. Локальные обложки получают responsive next/image, без разрешения оптимизировать произвольные внешние URL.
- Для публичных фото API передаёт реальные размеры производного изображения, не оригинала. Добавлены атрибуты размеров там, где они достоверно известны, отложенная загрузка второстепенных изображений и приоритет изображения первого экрана. Пропорции плитки и CSS не менялись.
- Добавлена доступная подпись загрузки файла и содержательные alt у обложек/примеров работ; декоративные изображения не озвучиваются повторно.
- Отключён X-Powered-By. Добавлены nosniff, SAMEORIGIN, referrer/permissions policies и CSP с уникальным nonce на каждый HTML-ответ. JavaScript production не разрешает unsafe-inline/unsafe-eval. Карта, внешние изображения, blob-превью, загрузка файлов и геолокация остаются разрешены.
- Для HTTPS добавлен HSTS на 30 дней без includeSubDomains/preload. Для изменяемых статических изображений используется короткий кеш с revalidation, не годовой immutable. Caddy-шаблоны дополнены заголовками и часовым кешем только публичных производных /media.

## Что сохранено намеренно

- Название бренда, видимые тексты, цвета, размеры, меню, карточки, сетки, модальные окна и все пользовательские действия. Нет CSS-изменений.
- Старые ссылки с query-параметрами: они индексируемы при корректных canonical, ссылках и HTML. Переименование URL не является обязательным исправлением SEO.
- Перенаправление корня сайта по языку браузера/cookie. Поддомены других проектов не включены в HSTS.
- Нет автоматической установки аналитики, новых cookie, программ, зависимостей, фоновых мониторов или изменений производственной БД.

## Требует действий владельца или проверки на сервере

1. Развернуть коммит: сама правка исходников не обновляет production. Проверить страницы, sitemap и заголовки после перезапуска.
2. Объединить изменения доменного блока `infra/caddy/photoapp.metarp.top.caddy` с существующим `/etc/caddy/Caddyfile`. Не заменять весь файл: там могут быть другие сайты. Выполнить `sudo caddy validate --config /etc/caddy/Caddyfile && sudo systemctl reload caddy`. Удалённая конфигурация здесь не применялась.
3. Подтвердить владение в Google Search Console/Яндекс Вебмастере и отправить sitemap. Отсутствие HTML-тега не доказывает отсутствие DNS-верификации. У нас нет доступа к этим аккаунтам; индексацию и позиции гарантировать нельзя.
4. Аналитику подключать отдельно после выбора провайдера, идентификатора и необходимых настроек согласия. Без этих данных код отслеживания не добавлен.
5. Контраст, увеличение мобильных зон нажатия, видимый H1 и любые перестройки интерфейса не менялись по условию владельца. Семантические подписи исправлены без изменения оформления.
6. Повторить Lighthouse/PageSpeed и внешний аудит после развёртывания. Старые показатели не являются результатом этой проверки; улучшение скорости и индексации численно не заявляется.

## Ограничения

- Источник динамических sitemap ограничен 500 профилями, 1000 работами, 500 публикациями и 100 активными/будущими челленджами за запрос. При приближении к этим значениям нужна дополнительная пагинация sitemap, а не снятие ограничений БД. Разделение по языкам защищает от раздувания XML из-за hreflang.
- Отдельные батлы получают метаданные, когда доступны в публичной очереди. Закрытые батлы и материалы вне доступной очереди не продвигаются в sitemap; для постоянного архива потребуется отдельная публичная страница, что выходит за ограничение сохранения функционала.
- При недоступности публичного API интерфейс сохраняет прежний клиентский повтор загрузки; метаданные неполученного конкретного материала не разрешают его индексировать. Не кешируется персонализированный HTML.

## Выполненная проверка

- 199 тестов: 67 web, 129 API и 3 проверки запуска скомпилированного API. Все прошли.
- Production-сборка Next.js 15.5.24 прошла. Предупреждение о snapshot кеша webpack не является ошибкой компиляции.
- На отдельном локальном API с публичными тестовыми данными проверен исходный HTML ленты RU/EN, публичного профиля, фотографии, мероприятий, экспертов, челленджа и политики. Контент присутствует вне script-тегов, а не только в данных для гидратации.
- Проверены уникальность CSP nonce между запросами, nonce всех script-тегов, noindex личных/демо-страниц, перенаправления и HTTP 404.
- Оба типа sitemap разобраны строгим XML-парсером, включая экранирование `&` в ссылках на фотографии и x-default.
- Проверены ненулевые PNG-превью 1200×630 и 180×180, responsive image optimizer и заголовок кеширования изображений.
- В браузере проверены сетка, модальное окно, поиск и сброс на 1280×720 и 390×844. Изображения загрузились, горизонтального переполнения и ошибок JavaScript/CSP не обнаружено. CSS и структура инструментов не менялись.
- Рабочая БД, платежи и production-инфраструктура в этих проверках не использовались. Реальное развёртывание, полный сценарий PostgreSQL/MinIO и внешние SEO-показатели ещё требуют серверной проверки.

Технические справочники: [Next.js Metadata](https://nextjs.org/docs/app/api-reference/functions/generate-metadata), [Next.js CSP](https://nextjs.org/docs/app/guides/content-security-policy), [Google Sitemap](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap).

## Обновление через PuTTY

```bash
cd /opt/gprn && git pull --ff-only && docker compose --env-file .env.production -f docker-compose.production.yml build web && docker compose --env-file .env.production -f docker-compose.production.yml run --rm --no-deps migrate && docker compose --env-file .env.production -f docker-compose.production.yml up -d --no-build --no-deps --force-recreate api web worker
```

Этот релиз не добавляет миграций БД. Команда migrate безопасно применяет неприменённые миграции предыдущих релизов.

Проверка заголовков в PuTTY (ограничение времени, без изменения сервера):

```bash
timeout -s KILL 20 curl --max-time 15 -fsSI https://photoapp.metarp.top/ru/feed
```
